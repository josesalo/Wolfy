# Wolfy

Web app personal (PWA) de entrenamiento de fuerza, readaptación lumbar, natación y nutrición, con una mascota que evoluciona con el progreso real.

- Vanilla JS, sin dependencias ni servidor.
- Instalable en iPhone desde Safari (Compartir → Añadir a pantalla de inicio) y usable sin conexión.
- Los datos se guardan solo en el dispositivo, con copia de seguridad en JSON.
